# The AI Engineering Skills Map — Part 3: Software Engineering Fundamentals

**Author:** Andrew Ng  
**Source:** DeepLearning.AI  

## Summary

Knowing how software works is still very important, even when using AI tools to write code. AI coding tools can help developers build applications, but without proper knowledge, they may make mistakes or choose the wrong way to solve problems. Developers need to understand how to build websites and applications, manage data, and design systems properly. They must also know how to keep information safe and make sure their applications work correctly. Testing helps find problems before they affect users. Developers should also understand how to put their applications online, maintain them, and handle more users as they grow. Knowing how to use Git, review code, and manage changes is also important. Overall, AI can make coding easier, but understanding software engineering helps developers make better decisions and build stronger applications.

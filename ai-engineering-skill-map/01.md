# The AI Engineering Skills Map

**Author:** Andrew Ng  
**Topic:** AI Engineering  
**Source:** DeepLearning.AI

## Summary

AI is changing how we build software, creating new opportunities for developers to learn and work.  
Research and expert interviews identified four important AI engineering skills.  
The first is building and deploying AI applications that work reliably despite AI sometimes making mistakes.  
The second is understanding software engineering fundamentals, including testing, security, privacy, and system design.  
The third is learning to use AI coding agents effectively to write, improve, and test code.  
Developers must understand the limitations of coding agents and guide them to produce better results.  
The fourth skill is shaping the build by identifying problems and deciding what software should accomplish.  
Developers need to understand users' needs and goals, not just write code.  
AI tools can help developers work faster, but human judgment is still important for making good decisions.  
Finally, developers must keep learning because AI technology and best practices change quickly.

# The AI Engineering Skills Map — Part 4: Using Coding Agents

**Author:** Andrew Ng  
**Source:** DeepLearning.AI  

## Summary

Coding agents are AI tools that can help developers write code, test applications, find problems, and carry out other tasks. To use them properly, developers need to know how to guide them from the beginning to the end of a project. This starts with planning what to build, understanding the problem, and giving the AI clear instructions. Next, the developer allows the AI to do some of the work but checks its results to make sure everything is correct. After building the application, it must be tested, put online, and monitored for problems. Developers also need to understand when to let the AI work on its own and when to step in and guide it. They should give the AI useful information about the project, provide the right tools, and make sure it works safely. Most importantly, developers should never trust everything an AI coding agent produces without checking it. Using coding agents effectively requires good planning, patience, regular testing, and human judgement.
